# ParLamassu

A simple ParLamassu Agent for Stateful Session Management.

ParLamassu is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- A simple ParLamassu Agent for Stateful Session Management

## Key Features

## Technology Stack

- typescript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/ParLamassu.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ParLamassu is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
